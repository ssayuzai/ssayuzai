# ssayuz AI

질문하면 인터넷을 검색하고, 웹페이지 여러 개를 읽은 다음, 출처 번호 [1][2]를 붙여 한국어로 답해 주는 검색 AI예요.
돈이 드는 API는 쓰지 않아요. 검색은 DuckDuckGo, AI는 내 컴퓨터에서 돌아가는 Ollama를 써요.

```
(이어지는 질문이면) 이전 대화를 보고 질문 이해하기
  → DuckDuckGo 검색 → 페이지 동시에 읽기
  → 빠른 답: 원문에서 찾은 문장 (약 7초)
  → AI 정리: 출처 번호 [1][2]가 붙은 답 (약 1분)
```

## 필요한 것

- Windows 10/11
- Python 3.10 이상 (3.12에서 확인함)
- RAM 8GB 이상 (16GB 권장). 그래픽카드가 없어도 CPU로 돌아가요.
- 디스크 여유 공간 약 5GB (Ollama 1.6GB + 모델 2.7GB + 파이썬 패키지)

## 설치

### 1) 파이썬 가상환경과 패키지

이 폴더에서 PowerShell을 열고 차례대로 실행해요.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

> `.venv`는 이 프로젝트 전용 "작은 파이썬 상자"예요. 여기에 패키지를 깔아서 다른 프로그램과 섞이지 않게 해요.
> 이 README의 명령은 `Activate.ps1`을 쓰지 않고 `.venv\Scripts\python.exe`를 바로 불러요. 그래서 PowerShell 보안 설정을 바꿀 필요가 없어요.

### 2) Ollama 설치 (직접 하기)

Ollama는 AI 모델을 내 컴퓨터에서 돌려 주는 무료 프로그램이에요.

1. https://ollama.com/download 에 들어가서 **Download for Windows**를 눌러요.
   - 받는 파일: `OllamaSetup.exe` (약 **1.6GB**, 2026년 10월 v0.35.1 기준)
   - 실제로는 GitHub(github.com/ollama/ollama)의 공식 릴리스에서 받아져요.
2. 받은 `OllamaSetup.exe`를 실행하고 **Install**을 눌러요.
3. 설치가 끝나면 Ollama가 작업 표시줄 오른쪽 아래(트레이)에서 저절로 켜져요.
4. **새** PowerShell 창을 열고 확인해요.
   ```powershell
   ollama --version
   ```

### 3) AI 모델 받기

```powershell
ollama pull qwen3.5:2b
```

- 받는 것: 알리바바 Qwen 3.5 (20억 파라미터, 한국어 포함 다국어 지원)
- 크기: 약 **2.7GB** / 출처: ollama.com 모델 저장소
- 라이선스: **Apache 2.0** (상업적으로 써도 돼요)

상업적으로 쓸 수 있는 다른 모델도 있어요. 모델을 바꿀 때는 `brain.py`의 `MODEL` 한 줄만 고치면 돼요.

| 모델 | 크기 | 라이선스 | 특징 |
|---|---|---|---|
| `qwen3.5:2b` | 2.7GB | Apache 2.0 | 기본 추천 |
| `qwen3:1.7b` | 1.4GB | Apache 2.0 | 더 가볍고 빠름 |
| `qwen3:4b` | 2.5GB | Apache 2.0 | 더 똑똑하지만 CPU에서 느림 |
| `gemma4:e2b` | 4.6GB | Apache 2.0 | 파일이 큼 |

> 쓰지 않는 모델: `exaone3.5`는 비상업용 라이선스라 제외했어요. `llama3.2`는 상업적으로 쓸 수 있지만 한국어가 공식 지원 언어가 아니에요.

### 4) 준비 점검

```powershell
.\.venv\Scripts\python.exe check_setup.py
```

모든 줄이 `[완료]`면 준비가 끝난 거예요. `[필요]`가 있으면 그 줄에 적힌 대로 해결하면 돼요.

## 실행

### 웹 화면에서 쓰기 (`app.py`) - 추천

```powershell
.\.venv\Scripts\python.exe app.py
```

브라우저가 저절로 열려요. 안 열리면 브라우저 주소창에 `http://127.0.0.1:7860`을 입력하세요. 끝낼 때는 실행한 창에서 Ctrl+C를 눌러요.

- 처음에는 **회원가입**을 해요. 아이디(한글, 영어, 숫자, _ 로 2~20글자)와 비밀번호(8글자 이상)만 받아요.
- 왼쪽에 **지난 대화 목록**이 있어요. 눌러서 다시 보거나, ✕로 지울 수 있어요. 휴대폰처럼 좁은 화면에서는 "☰ 기록" 단추로 열어요.
- 같은 대화에서 **"그럼 토성은?"처럼 이어서** 물어보면 앞 질문을 보고 "토성의 위성은 몇 개야?"로 이해해요.
- 진행 단계와 걸린 시간을 실시간으로 보여 줘요. **원문에서 찾은 문장이 먼저(약 7초)** 나오고, **AI 정리가 이어서(약 1분)** 나와요.
- 답의 출처 번호를 누르면 그 웹페이지가 새 탭으로 열려요.
- **내 컴퓨터에서만 접속할 수 있어요**(`127.0.0.1`). 같은 와이파이의 다른 사람은 들어올 수 없어요.
- 질문은 한 번에 하나씩 처리해요. AI가 CPU를 다 쓰기 때문이에요. 다른 탭에서 동시에 물으면 앞 질문이 끝날 때까지 기다려요.

## 데이터 저장 (`db.py`)

- Python에 기본으로 들어 있는 **SQLite**를 써요. 따로 설치할 게 없어요.
- 모든 데이터는 `data` 폴더에 저장돼요.
  - `data/ssayuz.db` : 회원, 대화방, 질문과 답 기록
  - `data/secret_key` : 로그인 상태를 지키는 비밀 열쇠 (처음 실행할 때 무작위로 만들어요)
- **`data` 폴더는 다른 사람에게 보내거나 인터넷에 올리면 안 돼요.** (`.gitignore`에 넣어 뒀어요)
- 검색이 실패한 질문도 기록에 남아요(오류로 표시).

## 보안

- 비밀번호는 원래 글자를 저장하지 않고 `scrypt` 방식으로 바꾼 값(해시)만 저장해요. DB가 새어 나가도 원래 비밀번호를 알 수 없어요.
- 로그인을 5번 틀리면 5분 동안 막아요. 아이디가 틀렸는지 비밀번호가 틀렸는지는 알려 주지 않아요.
- 남의 대화방은 볼 수도, 지울 수도, 이어서 물을 수도 없어요.
- 로그인 쿠키는 페이지의 자바스크립트가 읽을 수 없고(HttpOnly), 다른 사이트에서 보낸 요청에는 붙지 않아요(SameSite=Lax). 서버는 JSON 요청만 받아요.
- 웹페이지 제목이나 AI 답에 HTML이 섞여 있어도 글자 그대로 보여 줘요. 링크는 http, https만 허용해요.

- Ollama는 매번 지시문을 처음부터 다시 읽어요(캐시가 안 돼요). 그래서 지시문을 짧게 줄였어요.

## 각 부분 따로 시험하기

### 검색 (`search.py`)

```powershell
.\.venv\Scripts\python.exe search.py 목성의 위성은 몇 개야
```

- 세이프서치는 항상 "엄격"으로 켜져 있어요. ddgs 패키지는 DuckDuckGo에 세이프서치와 지역 설정을 제대로 전달하지 않아서, `search.py`가 DuckDuckGo가 알아듣는 이름(`kp=1`, `kl=kr-kr`)으로 직접 붙여요.
- 안전망을 하나 더 두었어요. 결과 주소에 성인 사이트 단어가 들어 있으면 빼요(`BLOCKED_HOST_WORDS`).
- 구글이나 빙 같은 다른 검색엔진은 쓰지 않고 DuckDuckGo만 써요.
- DuckDuckGo는 2초 간격 연속 검색도 막아요. 그래서 질문 하나에 **한 번만** 검색해요. 막히면 1~2분 기다렸다가 다시 하면 돼요.

### 페이지 본문 읽기 (`reader.py`)

```powershell
# 주소 하나 읽기
.\.venv\Scripts\python.exe reader.py https://ko.wikipedia.org/wiki/목성의_위성
# 검색하고 페이지 읽기
.\.venv\Scripts\python.exe reader.py 목성의 위성은 몇 개야
```

- 메뉴, 광고, 댓글은 빼고 본문만 뽑아요(`trafilatura`).
- 검색 결과 위쪽 6개를 **동시에** 받고, 7초가 지나면 받은 것 중 순위가 높은 3개를 써요.
- 사이트의 **robots.txt(로봇 출입 규칙)를 지켜요.** 표준 규칙(RFC 9309)대로 해석하려고 `protego`를 써요.
- 사이트에 우리 이름표(`ssayuzAI`)를 솔직하게 보여 줘요.
- 이런 페이지는 건너뛰어요: 8초 넘게 걸림, 3MB보다 큼, 웹페이지(HTML)가 아님, 사이트가 거절함(403/404 등), 본문이 200자보다 짧음.
- 네이버 블로그는 모바일 주소(`m.blog.naver.com`)로 바꿔서 읽어요.

### AI 두뇌 (`brain.py`)

```powershell
.\.venv\Scripts\python.exe brain.py 목성의 위성은 몇 개야
```

- `rewrite_question`: "그럼 토성은?" 같은 이어지는 질문을 혼자서도 뜻이 통하는 질문으로 바꿔요. 바뀐 질문에 원래 질문의 핵심 낱말이 절반도 없으면, AI가 엉뚱하게 바꾼 것으로 보고 원래 질문을 써요.
- `quick_answer`: AI 없이, 질문과 관련 있는 원문 문장을 골라요. 드물게 나오는 낱말("출생")일수록 점수를 더 줘요.
- `write_answer`: 페이지에서 관련 문단만 골라(총 1500자) AI에게 보여 주고, 출처 번호가 붙은 답을 받아요.
- 작은 AI가 지어내지 않게 **프로그램이 한 번 더 검사해요.**
  - **미리 확인하기:** 질문의 핵심 낱말이 자료에 거의 없으면 AI를 부르지 않고 바로 "찾지 못했어요"라고 답해요.
  - **근거 확인:** 문장마다 숫자가 자료에 있는지, 중요한 낱말이 절반 이상 자료에 있는지 확인해요. 근거 없는 문장은 빼고, 출처 번호가 틀렸으면 고쳐요.
  - 뜻을 반대로 쓰는 실수(예: "빼고"를 "포함해서"로)는 낱말이 같아서 잡지 못해요.
- AI의 '속으로 생각하기(thinking)'는 꺼요. 모델은 30분 동안 메모리에 올려 둬요.

## 상업적으로 쓸 때 주의할 점

- **검색 부분(ddgs)**: ddgs 패키지 자체는 MIT 라이선스예요. 하지만 DuckDuckGo가 공식으로 제공하는 API가 아니에요. 서비스로 출시하기 전에는 DuckDuckGo 이용약관을 확인하거나 공식 검색 API로 바꾸는 걸 검토해야 해요.
- **웹페이지 내용**: 원문은 짧은 문장 몇 개만 출처 링크와 함께 보여 주고, 길게 그대로 옮기지 않아요.
- **robots.txt**: 네이버 블로그는 GPTBot, PerplexityBot 같은 AI 로봇을 이름까지 적어서 막고 있어요. `ssayuzAI`라는 이름은 거기 없어서 지금은 읽을 수 있지만, 출시 전에는 네이버의 이용약관도 확인해 보세요.
- **회원 정보**: 서비스로 공개하면 개인정보 처리방침이 필요하고, 반드시 HTTPS로 서비스해야 해요. Flask의 개발용 서버 대신 `waitress` 같은 정식 서버를 써야 해요.
- 라이선스와 약관에 대한 최종 판단은 법률 전문가와 확인하는 게 안전해요.
